# Security policy

## Reporting a vulnerability

Please report security issues privately to the repository owner through GitHub's **Report a vulnerability** feature (Security tab). Do not create a public issue for a vulnerability that could expose private conversations or extension data. The public repository URL will be configured before the first release.

## Security and privacy guarantees

- No chat content is transmitted, logged, or persisted by this extension.
- No telemetry, analytics, or remote code is used.
- Content processing is limited to the three supported chat sites.
- User preferences are stored with the browser's extension storage API.
- Avoid adding permissions, dependencies, or network access unless strictly required and reviewed.
