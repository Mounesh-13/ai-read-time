# Privacy policy

**AI Read-Time Indicator collects nothing.** There is no telemetry, analytics, advertising, account, or remote service.

The content script reads rendered assistant-message text from the current page solely to calculate a reading-time estimate. Text and code remain in the browser's memory; they are not sent to the extension developer or any third party, and are not saved by this extension. Only user-selected preferences (such as WPM and enabled sites) are stored in the browser's built-in extension settings storage (`storage.sync`).

The extension requests the `storage` permission and is limited to the supported AI chat hosts. It does not make network requests. The optional “Report a broken site” action opens a GitHub issue draft containing the selected site and browser user-agent string; it never includes chat content. The user reviews and submits that draft themselves.
